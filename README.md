# Transformer Attention Analysis

> **Applied AI portfolio project by Brent Oatis, MBA**
> Building practical understanding of transformer attention, interpretability, and model behavior.

## Portfolio summary

This project explores transformer attention mechanics through notebook-based experiments and visual analysis. It is designed to make model behavior more understandable and to connect modern NLP architecture with responsible, evidence-based deployment decisions.

## Operational relevance

Attention analysis supports model literacy, explainability, validation, and risk-aware adoption of generative AI in business and operational settings.

## Technical scope

- Python and Jupyter
- Transformer architectures
- Self-attention and attention weights
- Visualization and interpretability
- Experimental model analysis

## Repository contents

The repository contains the source notebook and supporting project materials used to investigate attention behavior.

## Professional context

Part of an applied AI portfolio focused on turning technical methods into useful systems for manufacturing, operations, and organizational decision-making.
